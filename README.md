# gameShelf

A collection of browser-based games built with vanilla HTML, CSS, and JavaScript — no downloads required. Play classic games right in your browser.

## Getting Started

1. Clone the repository.
2. Open `index.html` in a browser, or serve it with any static file server (e.g. `npx serve .`).
3. Add games to the `games/` directory following the conventions in `AGENTS.md`.
